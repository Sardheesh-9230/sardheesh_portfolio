## Image Requirements

- **Size**: 400x300px (4:3 aspect ratio)
- **Format**: PNG or JPG
- **Quality**: High resolution for retina displays
- **Content**: Screenshots showing the actual project interfaces

## Adding New Images

To add a new project image:
1. Take a screenshot of your project's main interface
2. Resize to 400x300px
3. Save in this directory with a descriptive filename
4. Update the project's `image` property in `ProjectsSection.tsx`

## Fallback Behavior

If an image file is not found, the project card will display:
- A gradient background with the project's theme color
- The project's icon
- A technology badge overlay
