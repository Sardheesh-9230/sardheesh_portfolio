# Sardheesh Portfolio

A stunning, professional 3D animated portfolio showcasing mobile app development and data analytics expertise built with React.js, Three.js, and Framer Motion.

## ✨ Features

### 🎨 **Visual Excellence**
- **3D Animations**: Immersive Three.js/React Three Fiber 3D scenes
- **Smooth Transitions**: Framer Motion powered animations
- **Responsive Design**: Mobile-first design that works on all devices
- **Dark/Light Theme**: Animated theme switching with 3D transitions
- **Particle Effects**: Dynamic floating particle backgrounds
- **Gradient Animations**: Eye-catching animated gradients

### 📱 **Mobile App Development Showcase**
- Interactive 3D phone mockups
- Project demonstrations with animated UI
- Technology stack highlights (React Native, Flutter)
- Mobile-optimized user experience

### 📊 **Data Analytics Dashboard**
- Interactive data visualizations
- Real-time chart animations
- Machine learning project highlights
- Analytics metrics and KPIs

## 🛠️ Tech Stack

- **Frontend**: React 19 + TypeScript
- **3D Graphics**: Three.js + React Three Fiber + Drei
- **Animations**: Framer Motion
- **Styling**: Tailwind CSS
- **Build Tool**: Vite
- **Icons**: Lucide React

## 🚀 Quick Start

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Installation

1. **Install dependencies**
   ```bash
   npm install --legacy-peer-deps
   ```

2. **Start development server**
   ```bash
   npm run dev
   ```

3. **Open in browser**
   Navigate to `http://localhost:5173`

### Available Scripts

- `npm run dev` - Start development server
- `npm run build` - Build for production
- `npm run preview` - Preview production build
- `npm run lint` - Run ESLint
